# Tidal Rush: Jet Ski (Free Demo)

Race jet skis through waves, weather and winding buoy-lined courses, right in your browser.

**Play the demo:** _add your GitHub Pages link here_

## What's in the demo

- **Training mission** that teaches every control
- **Mission 1: Harbor Dash**, 3 laps against 3 AI riders
- **Viper jet ski** with its Dash ability
- **6 weather types** (sunny, cloudy, windy, dusty, rainy, tornado) and **4 difficulties** (Easy to Extreme)
- First-person and third-person cameras, wave crashes, camera shake and a minimap with a checkpoint arrow

The full game adds 10 missions, 3 jet skis with different abilities, and upgrades.

## Controls

| Action | Keyboard | Touch |
|---|---|---|
| Throttle / Brake | W or Up / S or Down | GO / BRAKE |
| Steer | A, D or Left, Right | Left, Right buttons |
| Nitro | Hold Shift while accelerating | NITRO |
| Ability (Dash) | Space | SKILL |
| First / third person | C | CAM |
| Restart / Menu | R / Esc | Menu button (top right) |

Tip: in tornado weather, hold Shift + W (nitro) to escape the funnel. Touch screens show the on-screen buttons automatically.

## Requirements

A modern browser (Chrome, Edge, Firefox or Safari) with WebGL and an internet connection. The game loads the three.js library from a CDN. Progress is not saved in the demo.
